# `MatBox`
`MatBox` is a local-first asset library for creators who need more than folders.  
Import your creative files, preview them quickly, and organise them with tags, collections, projects, and goals so the right asset is easier to find when you need it.  

Use `MatBox` to build a searchable home for textures, icons, fonts, sound effects, music, 3D models, materials, shaders, documents, archives, and other project files.  
Your library stays on your device, with no account or cloud upload required.  

`MatBox` is designed for artists, game developers, designers, audio creators, and anyone managing a growing set of creative files.  
It helps turn scattered folders into a focused library you can browse, preview, and plan around.

## Features
* Import and organise creative assets in a dedicated local library
* Preview common file types including images, audio, fonts, PDFs, text, and Markdown, with support for more formats planned for future updates
* Search, filter, and sort assets by name, type, tags, collections, favourites, and notes
* Add custom tags with colours and icons for quick visual organisation
* Group related assets into collections for reusable themes, packs, references, and workflows
* Create projects to connect assets with bigger creative goals
* Build project plans with goals, tasks, priorities, statuses, due dates, and linked assets
* Keep important files easy to find with favourites and saved metadata
* Restore deleted items from the recycle bin before removing them permanently
* Move your library location when your storage setup changes
